# SafeTalk Q3/2026 Reader

เว็บแอป (PWA) สำหรับอ่านและทบทวน **SafeTalk Q3/2026** (by Gryffindor) — 43 คำถามใน 3 หมวด

- **Safety & Procedures** (20 ข้อ แยก Airbus/Boeing ในข้อ 13, 15, 19)
- **First Aid** (15 ข้อ)
- **Security** (5 ข้อ)

## ฟีเจอร์
- **สอบเสมือนจริง** — เลือกตอบ (ตรวจอัตโนมัติ) หรือเขียน/พูดตอบ (ตรวจเองเทียบคู่มือ พร้อมเทียบคำสำคัญ) · เลือกจำนวนข้อ เวลา หมวด · เกณฑ์ผ่าน 80%
- **ฟังเสียง 🔊 / พูดตอบ 🎤** — อ่านคำถามและคำตอบออกเสียง (EN/TH) และพิมพ์หรือพูดตอบก่อนเปิดเฉลยในแฟลชการ์ด
- **แท็บ ฉัน** — สถิติแยกหมวด กราฟ 7 วัน ข้อที่ควรฝึก ประวัติสอบ คะแนนเกม · Streak + เป้าหมายรายวัน · เหรียญ 19 แบบ
- **ตั้งค่า** — ภาษา ขนาดตัวอักษร ธีม เป้าหมายรายวัน สำรอง/นำเข้าความคืบหน้า และเลือกไตรมาส
- **EN / TH** — ปุ่มสลับภาษาทั้งแอป (ค่าเริ่มต้นอังกฤษ) · ทุกข้อมีคำแปลไทย และ 💡 อธิบายง่าย + 🧠 ทริกจำ ทั้งอังกฤษ (`en.js`) และไทย (`th.js`) · ข้อความ UI อยู่ใน `i18n.js`
- **อ่าน** — แตะคำถามเพื่อเปิดคำตอบ (ภาพตัดจาก Cabin Crew Manual Iss.04 Rev.03 พร้อมเลขหน้า CCM) แตะรูปเพื่อซูม
- **แฟลชการ์ด** — ดูคำถาม → แตะดูคำตอบ → กด "จำได้แล้ว / ยังไม่แม่น", สุ่มลำดับ, เลือกเฉพาะข้อที่ยังไม่จำ
- **เกม** 4 เกม แต่ละเกมมี 3 ระดับ (ง่าย / กลาง / ยาก) จับเวลา หัวใจ คอมโบ และบันทึกสถิติสูงสุด
  - ทายภาพคำตอบ — ดูภาพคำตอบแล้วเลือกคำถาม
  - ถูกหรือผิด — ตัดสินข้อความจากคู่มือ
  - เรียงขั้นตอน — เรียงลำดับ procedure เช่น เปิดประตู ELT ดับไฟ DRCABD
  - ตัวเลขต้องจำ — ชั่วโมง นาที กก. % ความถี่ ตัวย่อ
- **เวอร์ชันและอัปเดต** — แตะป้าย `v1.x.x ⟳` ใต้ชื่อแอปเพื่อดูเวอร์ชันและรีเฟรชโหลดเวอร์ชันล่าสุด แอปจะขึ้นแถบแจ้งเตือนเองเมื่อมีเวอร์ชันใหม่
- **หน้าต้นฉบับ** — ดูทั้ง 8 หน้าของ PDF แบบเต็ม
- ค้นหา, กรองตามหมวด และตามแบบเครื่องบิน (Airbus / Boeing)
- เก็บความคืบหน้าไว้ในเครื่อง (localStorage) และใช้งานออฟไลน์ได้ (service worker)
- ติดตั้งลงหน้าจอโฮมได้ (Add to Home Screen)

## โครงสร้าง
```
index.html  style.css  app.js   แอป
game.js  gamedata.js             เกมและข้อมูลเกม (จาก CCM)
version.js  version.json  update.js   เวอร์ชันและการอัปเดต
data.js                         คำถาม + ไฟล์ภาพคำตอบของแต่ละข้อ
th.js                           คำแปลไทย อธิบายง่าย ทริกจำ
fonts/                          ฟอนต์ Mitr + IBM Plex Sans Thai Looped (OFL)
img/                            ภาพคำตอบที่ตัดจาก Cabin Crew Manual (WebP)
pages/                          ภาพหน้าเต็มของ SafeTalk PDF
sw.js  manifest.webmanifest     PWA / ออฟไลน์
```

## รันในเครื่อง
```
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000

## เพิ่ม SafeTalk ไตรมาสใหม่
1. สร้างไฟล์ข้อมูลแบบเดียวกับ `data.js`, `th.js`, `en.js`, `ans.js` โดยลงทะเบียนด้วย id ใหม่ เช่น `"2026Q4"` และตั้ง `imgBase` / `pagesBase` เป็นโฟลเดอร์ของไตรมาสนั้น
2. ใส่ `<script>` ของไฟล์ใหม่ใน `index.html` ก่อน `quarters.js` และเพิ่มชื่อไฟล์ใน `sw.js`
3. แอปจะเลือกไตรมาสล่าสุดให้อัตโนมัติ และผู้ใช้สลับไตรมาสได้ที่ชื่อไตรมาสบนหัวแอป (ความคืบหน้าแยกกันแต่ละไตรมาส)

## ออกเวอร์ชันใหม่
เปลี่ยนเลขเวอร์ชันให้ตรงกันทั้ง 3 ที่: `version.js`, `version.json` และ `CACHE` ใน `sw.js`
แอปในเครื่องผู้ใช้จะเห็นแถบ "มีเวอร์ชันใหม่" อัตโนมัติ
